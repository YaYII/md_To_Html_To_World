## [0.1.42] - 2025-07-07

### 🐛 关键修复 - Unicode字符显示问题

#### 🎯 特殊字符转换修复
- **问题解决**: 修复了🎯等Unicode特殊字符在HTML转Word过程中无法正确显示的问题
- **根本原因**: 文本处理器对纯文本节点中的Unicode字符没有应用合适的图标字体
- **技术方案**: 在文本处理器中添加Unicode字符检测，自动应用Segoe UI Emoji字体
- **混合文本支持**: 新增`processTextWithIcons`方法，精确处理既包含普通文本又包含Unicode字符的混合内容

#### 🔧 技术实现细节
- **智能字符检测**: 使用正则表达式`/[\u{1F300}-\u{1F9FF}\u{2600}-\u{26FF}\u{2700}-\u{27BF}]/u`检测Unicode图标
- **分段处理**: 将混合文本分割为普通文本和Unicode字符两部分，分别应用不同字体配置
- **字体优化**: Unicode字符默认使用Segoe UI Emoji字体，确保最佳显示效果
- **配置灵活性**: 支持通过配置文件自定义图标字体、大小和颜色

#### 📁 修改文件
- `nodejs/src/htmlToWord/processors/textProcessor.js` - 添加Unicode字符检测和处理逻辑

#### 🎯 修复效果
- ✅ 🎯字符现在可以在Word文档中正确显示
- ✅ 支持各种Unicode表情符号和特殊字符
- ✅ 混合文本（文字+图标）正确处理
- ✅ 在标题、段落、列表、表格等各种上下文中均正常工作

### 📋 使用方法

1. **安装插件**: 在 VS Code 扩展商店搜索 "Markdown to Word" 并安装
2. **自动初始化**: 插件会自动检测和安装所需依赖（首次使用）
3. **开始转换**: 
   - 右键点击 .md 文件，选择相应的转换命令
   - 或使用 Ctrl/Cmd+Shift+P 打开命令面板搜索命令
4. **配置调整**: 使用 `配置Word文档` 命令自定义转换设置
5. **批量处理**: 右键点击文件夹，选择批量转换命令
